# 사람이 판단하고 그리는 단계

자동 비교와 검수 자료 준비는 끝났습니다. 이제 “이 획이 무엇인지”, “실제로 어디로
선을 그어야 하는지”를 기록해 주세요. 처음에는 90개 모두 미검수이며 자동 승인은 없습니다.

## 바로 시작하기

1. 로컬 `data/derived/contour-chain-2026-09-12/human-review-ready/` 폴더의
   `human-review.qgz`를 QGIS로 엽니다. 별도 플러그인 설치 없이 일반 레이어 편집으로 검수할 수 있습니다.
   다른 컴퓨터에서는 묶음 ZIP을 먼저 풀고 **폴더 전체**를 옮기세요. QGZ만 옮기면 원본이 빠집니다.
2. 공간 북마크 패널의 **프로젝트 북마크**에서 `H001`부터 이동합니다.
   북마크 이름에 원 표본 ID와 타일이 있습니다. 레이어
   **“1 · 사례 판정 — 표에서 상태·승인 입력”**의 속성 테이블에서 해당 사례 행을 선택하세요.
   북마크 대신 행을 선택하고 “선택한 객체로 확대”를 사용해도 됩니다.
3. 파란색은 **판정할 원래 후보 선**입니다. 이 레이어를 잠시 꺼서 배경 지도부터 보고,
   다시 켜 대상의 범위를 확인하세요. 원래 선이 맞다는 뜻의 색이 아닙니다.
   `source-first-review.html`에서도 원본과 파란 대상 선을 나란히 볼 수 있습니다.
4. 사례 레이어의 편집 모드를 켜고 아래 ①~⑤를 입력합니다. 실제 경로를 고칠 때는
   원래 파란 선을 편집하지 말고 **“2 · 사람이 그린 선 — 보라”**에 따로 그립니다.
5. 편집한 각 레이어를 저장하고 편집 모드를 종료합니다. 프로젝트도 저장하고 QGIS를 닫은 뒤
   “검수 저장했어”라고 알려 주세요. 일부만 끝냈어도 괜찮습니다. 나머지는 미검수로 남겨 둡니다.

저는 새 검수 GeoPackage만 읽어 변경분을 확인합니다. 기존 사람 검수 파일은 건드리지 않습니다.
이 폴더에서 생성 명령을 다시 실행하지 마세요. 생성기는 기존 GPKG·QGZ를 덮어쓰지 않도록 막혀 있습니다.
검수 중에는 폴더를 백업하거나 동기화하지 말고, 편집을 저장하고 QGIS를 닫은 뒤 복사하세요.

## 무엇부터 볼까요?

| 순서 | 사례 | 개수 | 용도 |
| --- | --- | ---: | --- |
| 먼저 | H001–H014 | 14 | 이전 표본의 모호한 획, 학습용 |
| 이어서 | H015–H048 | 34 | 새 표본의 모호한 획·판정 변화, 평가 전용 |
| 그다음 | H049–H090 | 42 | 학습용 비교 표본, 기존 AI 양성·음성에서 각각 21개 선정 |

첫 48개는 오류·모호성의 원인을 파악하는 핵심 검수입니다. **48개만으로 학습량이
충분하다는 뜻은 아닙니다.** 학습용은 총 56개, 평가 전용은 34개입니다.
H049 이후의 기존 AI 양성·음성은 표집 기준일 뿐 정답이 아니므로 자유롭게 뒤집어 주세요.
한 번에 모두 할 필요는 없고, 첫 14개의 판단·수정만으로도 어떤 문제가 남는지 확인할 수 있습니다.

배경은 지금까지 추출에 사용한 **동일한 지리보정 타일**입니다. 아직 재표본화하지 않은
전체 원본 스캔이라는 뜻은 아닙니다. 확대해도 판단이 안 되면 추측으로 확정하지 않아도 됩니다.
`selection-audit.json`과 모델 전후 비교 화면은 독립 판단을 기록한 뒤 보는 것이 좋습니다.
사례 선정 자체에는 AI 라벨·모델 판정 변화가 사용됐으므로 무작위 전체 지도 평가 표본도 아닙니다.

## 사례 행의 ①~⑤

| 항목 | 입력할 내용 |
| --- | --- |
| ① 원래 선의 종류 (`review_status`) | 등고선 / 문자 / 도로·하천·둑 / 지도 기호 / 여러 종류 혼합 / 판독 불가 |
| ② 선 처리 (`geometry_decision`) | 원래 선 그대로 등고선 승인 / 정확한 선을 별도로 그리기 / 원래 선 제외 / 불명확—학습 제외 |
| ③ 판독자 이름 (`annotator`) | 실제 판독한 사람이 구분되는 이름 또는 일관된 식별명 |
| ④ 직접 확인·승인 (`human_approved`) | 그 사례의 판단을 직접 확인한 뒤 체크 |
| ⑤ 판단 근거 (`review_note`) | 왜 그렇게 봤는지, 어디에서 선이 섞였는지·가렸는지 |

승인은 “등고선이다”가 아니라 **이 사람이 이 판단을 확인했다**는 뜻입니다.
문자·도로 제외나 “판독 불가” 결정도 직접 확인했다면 승인할 수 있습니다.
판독 불가·혼합은 근거가 반드시 필요하고, 그 자체를 이진 분류 정답으로 학습하지 않습니다.

- 파란 선 전체가 보이는 등고선이고 경로도 맞음:
  **등고선 + 원래 선 그대로 등고선 승인**.
- 파란 선 전체가 도로·문자·기호:
  해당 종류 + **원래 선 제외**. 불필요하게 선을 다시 그릴 필요는 없습니다.
- 등고선이지만 경로가 잘못됐거나 일부만 맞음:
  **등고선 + 정확한 선을 별도로 그리기**, 보라 레이어에 올바른 가시 구간을 그립니다.
- 한 후보 안에 등고선과 다른 획이 섞임:
  **여러 종류 혼합 + 정확한 선을 별도로 그리기**, 맞는 부분과 제외할 부분을 따로 표시합니다.
  올바른 부분을 특정할 수 없으면 혼합 + 불명확 또는 원래 선 제외로 기록하고 이유를 적습니다.
- 원본을 봐도 구분할 수 없음:
  **판독 불가 + 불명확—학습 제외**, 이유를 적습니다. 미결정 상태라면 승인을 비워 둬도 됩니다.

사례 ID·용도·출처 해시와 사각형 도형, 읽기 전용 파란 원래 선은 수정하지 마세요.
그 정보가 바뀌면 가져오기가 중단됩니다. 사례 레이어에서는 위 다섯 속성만 편집합니다.

## 실제로 선을 그릴 때

1. 보라 **“2 · 사람이 그린 선”** 레이어를 선택하고 편집 모드를 켭니다.
2. “선 객체 추가”로 원본에서 보이는 획의 중심을 따라 점을 찍습니다.
   모든 주변 선을 완성할 필요는 없습니다. 확실히 판독되는 짧은 구간만 그어도 됩니다.
3. 새 선의 `case_id`에 지금 검수 중인 H 번호를 고르고, `trace_kind`를 꼭 지정합니다.
   한 사례에 여러 선을 그릴 수 있지만, 타일 밖이나 다른 사례의 위치에 그리지 마세요.

| 선 종류 | 기록하는 것 | 이후 처리 |
| --- | --- | --- |
| `observed_contour` — 실제로 보이는 등고선 | 원본에서 확인되는 올바른 경로 | 학습용 사례의 가시선 지도 자료 |
| `inferred_gap` — 사람이 추론한 연결 | 글자 가림·공백을 사람이 해석해 연결한 경로 | 별도 보관; 보이는 잉크 정답으로 학습하지 않음 |
| `hard_negative` — 제외할 획 | 도로·문자·기호 등 등고선이 아닌 경로 | 학습용 사례의 명시적 음성 자료 |

보이는 부분과 추론한 부분이 섞이면 **별도의 선 객체**로 나눠 주세요.
틀린 원래 선을 고칠 때는 보라 선을 추가한 후 사례 행의 “정확한 선을 별도로 그리기”도 선택합니다.
선 처리만 변경하고 새 선이 없으면 가져오기가 중단됩니다.

훼손·번짐·겹침으로 판독할 수 없는 영역은 **“3 · 판독 불가 영역 — 사선”**에서
다각형을 그려 같은 `case_id`와 `reason`을 적을 수 있습니다. 이를 배경 음성으로 학습하지 않습니다.
선을 그리지 않은 픽셀도 전부 “모름”입니다. 표시하지 않았다고 비등고선으로 간주하지 않습니다.

## 제가 무엇을 보고 배우게 되나요?

원래 후보와 사람이 그린 경로, 판정 이유, 출처 픽셀 좌표를 함께 남깁니다.
이를 보고 잘못된 분류·합류·끊김의 원인을 다시 분석하고 프로젝트의 모델 개선에 사용할 수 있습니다.

- 사람이 **원래 선 전체를 승인하거나 제외한** 학습용 판정은 선분 분류기 재학습에 사용할 수 있습니다.
- 사람이 **새로 고쳐 그린** 경로는 원래 선 전체의 양성 라벨로 바꾸지 않습니다.
  원래 경로/수정 경로 쌍과 희소 픽셀 정답을 별도 저장합니다. 이를 쓰는 새 경로 학습기의
  설계·학습·검증은 다음 단계이며, 현재 자동으로 신경망을 학습한 상태는 아닙니다.
- 평가 전용 E 계열 34개는 사람이 고쳐도 학습·임계값 선택에 넣지 않습니다.
  추론 연결도 가시선 정답과 분리합니다.
- 대화만으로 제 기반 언어모델이 영구 재학습되는 것은 아닙니다. 여기서 쌓는 학습은
  **이 프로젝트의 재현 가능한 사람 정답·수정선 자료와 분류 모델**입니다.

분류기 재학습의 기본 시작 조건은 학습용의 명시적 양성 20개·음성 20개 이상,
세 개발 도엽 포함, 도엽 제외 학습이 가능한 클래스 분포입니다. 이 숫자는 충분한 정확도의
보증이 아닙니다. 실제 사람 판정이 AI 표집과 달라지거나 수정선이 많으면 추가 표본이 필요할 수 있습니다.
조건을 채워도 연구 후보 모델만 만들고 기본 추출기를 자동 변경하지 않습니다.
현재 실제 파일은 승인 0개, 학습 실행 없음으로 확인했습니다.

## 개발자용: 저장 후 가져오기

사용자가 이 명령을 실행할 필요는 없습니다. 편집 저장 후 알려 주시면 이어서 처리합니다.
QGIS를 닫고, 매 실행에 새 출력 폴더를 지정하세요.

QGIS의 Python 환경(추가 Pillow 설치 불필요):

```sh
python scripts/import_contour_human_feedback.py \
  data/derived/contour-chain-2026-09-12/human-review-ready/packet.json \
  --output data/derived/contour-human-feedback-next
```

NumPy·SciPy·Pillow가 있는 별도 Python 환경:

```sh
python scripts/prepare_contour_feedback_training.py \
  data/derived/contour-chain-2026-09-12/human-review-ready/packet.json \
  data/derived/contour-human-feedback-next/feedback.json \
  --fit-if-ready --output data/derived/contour-human-training-next
```

다음 회차에는 가져오기 명령에 `--previous-feedback 이전/feedback.json`을 추가해
변경된 판정 ID와 이전 파일 해시를 보존할 수 있습니다. 수정선 내용도 매 회차 전체 스냅샷에 남습니다.
가져오기 전후 GPKG 해시가 같아야 하며 출처 이미지·원래 도형·사례 용도를 확인합니다.
QGIS 좌표 직렬화의 극미세 오차만 허용하고, 원래 선을 고쳐 쓴 경우에는 중단합니다.
